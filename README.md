### Machine learning project - predicting train delays

- data was preprocessed using the "clean" scripts in order
- data4 is the final data after preprocessing.
- other data is stored locally since they are too big to commit to github
- count_trains counts the total number of data points (~71,000)
- delay_rate_by_traintype calculates the delay rate for the different train types
- to_csv takes filtered-data4 and transforms all of it into trains.csv
